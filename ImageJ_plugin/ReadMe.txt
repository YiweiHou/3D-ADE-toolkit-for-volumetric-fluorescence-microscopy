For users' convenience, we release an ImageJ version of the software. To run the ImageJ version, please place this .jar file in the plugin folder of your ImageJ. MATLAB Runtime 2022b (9.13) version is needed to run this ImageJ plugin, which can be downloaded freely from: https://www.mathworks.com/products/compiler/matlab-runtime.html (official link, free), or in: https://doi.org/10.6084/m9.figshare.30730169.v1 (we pre-uploaded).
